# Efferis by Lumora — Homepage Demo Bundle

This bundle includes:
- `index.html` — starter homepage demo
- `assets/css/styles.css` — styling
- `assets/js/main.js` — simple interactions and reveal animations
- `assets/images/` — generated product visuals + original reference image
- `cursor_prompt.txt` — a ready prompt to continue building the site in Cursor/Codex

## Quick Start
1. Unzip the folder.
2. Open `index.html` in your browser to preview the homepage demo.
3. Use the assets inside `assets/images/` for web sections, ads, and mockups.
4. Open `cursor_prompt.txt` and paste it into Cursor to continue building the full website.
